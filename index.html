William MacKinnon: open-source security tooling for Linux and macOS

  • AsahiLocker — encrypt an installed Fedora Asahi Remix system on Apple Silicon with LUKS2, in place: no reinstall, macOS untouched
  • LinuxLocker — the same in-place LUKS2 encryption for other Linux distributions and filesystems
  • Panoptes — Linux network monitoring, DNS hardening and intrusion investigation
  • Panoptes-macOS — macOS Secure Network: private DNS, a WARP kill-switch and intrusion alerts (formerly macOS-SecureNetwork-Suite)
